# TPI – Sistema de Gestión de Inventario y Trazabilidad de Donaciones

**Organización:** Proyecto Andrés 5 panes y dos peces (comedor solidario, Rosario).
**Materia:** Organización Empresarial – Tecnicatura Universitaria en Programación, UTN.
**Alumno:** Waldo Martin Gonzalez.

El sistema busca asegurar la provisión de insumos, evitar quiebres de stock y garantizar la elaboración diaria de **100 raciones** de comida. También da transparencia a los donantes.

## Recorrido del TPI

1. **Entrega 1. La organización y su enfoque sistémico:** entradas, procesos, salidas, ambiente y módulo propuesto.
2. **Entrega 2. Diagnóstico y planeación:** FODA, objetivo y metas, y Gantt (23/10 – 22/12/2026).
3. **Entrega 3. Estructura formal y datos:** organigrama y diccionario de datos.
4. **Entrega 4. Procesos y control:** BPMN, Git/GitHub, backlog ágil e indicadores.

## Cómo se trabajó

- **Ramas:** `main` guarda la versión estable. Cada tarea se hace en su propia rama (`feature/...` o `docs/...`) y entra a `main` por **Pull Request**.
- **Commits:** mensajes descriptivos con prefijo: `docs:` para documentación, `feat:` para contenido nuevo y `fix:` para correcciones.
- **Tablero:** GitHub Projects, con las columnas *Backlog → Por hacer → En progreso → En revisión → Hecho*. Ver el enlace en el PDF final.
